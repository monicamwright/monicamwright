## Why the repos are private

They hold client work, my job search, and personal writing. Here's what's in them.

**content-brain** is my writing system. My voice rules, beliefs, stories, and case studies live in plain markdown files that any AI model reads before it drafts anything. Skills handle the repeat work: LinkedIn drafts, newsletter issues, voice checks, and idea capture.

It also runs my job search. It drafts cover letters into Google Docs, updates a Notion tracker, and flags follow-ups. I edit every draft. Nothing publishes or sends on its own.

I picked GitHub over a chat window for the version history. When I rewrite a draft, the diff shows exactly what I changed. If I keep fixing the same thing, it becomes a rule.
